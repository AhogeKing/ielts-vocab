# PostgreSQL learning

## 创建库、模式

数据库操作

```postgresql
--- 创建数据库
create database db_name;

--- 查看数据库
\l 或者 SELECT datname FROM pg_database;

--- 接入数据库
\c db_name;

--- 删除数据库
drop database db_name;  -- 需要先切换到其他数据库才能删除，并且不能有会话连接
DROP DATABASE db_name WITH (FORCE); -- 强制删除 

-- 查看模式
\dn

-- 如果不存在，创建模式
CREATE SCHEMA IF NOT EXISTS storage;

-- 删除模式
-- 只有模式为空时才能删除
DROP SCHEMA IF EXISTS storage;

-- 级联删除：删除模式以及模式里的所有表、视图、函数等
DROP SCHEMA IF EXISTS storage CASCADE;
```

## psql 表操作

### 1. 创建表 (CREATE TABLE)

在创建表时，除了字段名和类型，**约束**也是保证数据质量的关键。

```postgresql
-- storage.files 表示在 storage 下创建 files 表
-- 如果需要在 public schema 下创建表，直接写 files 或者 public.files
CREATE TABLE IF NOT EXISTS storage.files
(
    id         BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, -- 自增主键
    file_id    UUID        DEFAULT gen_random_uuid(),               -- uuid
    file_name  TEXT NOT NULL,                                       -- 不能为空
    file_size  BIGINT CHECK ( file_size > 0 ),                      -- 检查约束，必须大于零
    is_public  BOOLEAN     DEFAULT false,                           -- 默认值
    tags       TEXT[],                                              -- 数组类型
    created_at timestamptz DEFAULT now()                            -- 带时区的时间
);
```

### 2. 查看数据库下的表 \d / \d+

```postgresql
SELECT
    schemaname AS 模式名,
    tablename AS 表名,
    tableowner AS 所有者
FROM pg_tables
WHERE schemaname NOT IN ('pg_catalog', 'information_schema')
ORDER BY schemaname, tablename;
```

### 3. 查看表的结构 \d table_name 或 \d+ table_name

\d 查看字段结构

```postgresql
SELECT
    c.ordinal_position AS 序号,
    c.column_name AS 字段名,
    c.data_type AS 数据类型,
    c.udt_name AS PostgreSQL类型,
    c.is_nullable AS 是否允许为空,
    c.column_default AS 默认值,
    c.character_maximum_length AS 最大长度,
    col_description(
            format('%I.%I', c.table_schema, c.table_name)::regclass::oid,
            c.ordinal_position
    ) AS 字段注释
FROM information_schema.columns AS c
WHERE c.table_schema = 'public'
  AND c.table_name = 'files'
ORDER BY c.ordinal_position;
```

更接近 \d+ files 的字段信息

```postgresql
SELECT a.attnum                                        AS 序号,
       a.attname                                       AS 字段名,
       pg_catalog.format_type(a.atttypid, a.atttypmod) AS 数据类型,
       CASE
           WHEN a.attnotnull THEN 'NO'
           ELSE 'YES'
           END                                         AS 是否允许为空,
       pg_get_expr(ad.adbin, ad.adrelid)               AS 默认值,
       CASE a.attidentity
           WHEN 'a' THEN 'GENERATED ALWAYS AS IDENTITY'
           WHEN 'd' THEN 'GENERATED BY DEFAULT AS IDENTITY'
           ELSE NULL
           END                                         AS identity属性,
       col_description(a.attrelid, a.attnum)           AS 字段注释
FROM pg_catalog.pg_attribute AS a
         LEFT JOIN pg_catalog.pg_attrdef AS ad
                   ON ad.adrelid = a.attrelid
                       AND ad.adnum = a.attnum
WHERE a.attrelid = 'public.files'::regclass
  AND a.attnum > 0
  AND NOT a.attisdropped
ORDER BY a.attnum;
```

### 4. 修改表 (ALTER TABLE)

- **添加字段**
  ```postgresql
  ALTER TABLE files ADD COLUMN download_count INT DEFAULT 0;
  ```
- **修改字段类型**  
  ```postgresql
  ALTER TABLE files ALTER COLUMN file_name TYPE VARCHAR(255);
  ```
- **重命名字段**
  ```postgresql
  ALTER TABLE files RENAME COLUMN is_public TO is_shared;
  ```
- **删除字段**
  ```postgresql
  ALTER TABLE files DROP COLUMN tags;
  ```

### 5. 删除表 (DROP TABLE)

删除表会删除表内所有数据。

```postgresql
-- 基本删除
DROP TABLE IF EXIST files;

-- 级联删除 (如果这个表被其他表作为外键关联，用 CASCADE 会连带删除关联)
DROP TABLE files CASCADE;
```

### 6. 清空表 (TRUNCATE)

删除表里所有的数据，但保留表的结构。`TRUNCATE` 比 `DELTE` 快得多。

```postgresql
TRUNCATE TABLE files;
TRUNCATE TABLE files RESTART IDENTITY; -- 清空表并重置自增 id
```

### 7. 查看表信息 (元指令与查询)

- 在 psql 命令行中

  `\dt`: 列出当前库所有表

  `\d files`: 查看这张表的详细结构 (列、类型、索引、约束)

- 使用 `SQL` 查询
  ```postgresql
  SELECT column_name, data_type, is_nullable
  FROM information_schema.columns
  WHERE table_name = 'files';
  ```

### 8. 特色操作：表继承 (Inheritance)

```postgresql
-- 父表：定义基础字段
CREATE TABLE content (
	title TEXT,
  author TEXT
);

-- 子表：继承基础字段，并增加自己的字段
CREATE TABLE video (
	duration INT
) INHERITS (content);
```

查询 `content` 表时，会自动把 `video` 表里的数据也查出来。

## 数据操作

数据的增删改查。

### 插入

```postgresql
-- 插入单条记录 (数组用 ARRAY[...] 或 {'a', 'b'} 语法)
INSERT INTO files (file_name, file_size, is_public, tags)
VALUES ('课程大纲.pdf', 1024576, true, ARRAY['教育', 'PDF']);

-- 批量插入
INSERT INTO files (file_name, file_size, is_public, tags)
VALUES
	('demo.mp4', 5000000, '{"视频", "测试"}'),
	('config.yaml', 1024, '{"配置"}');
```

如果约束失败，自增 id 仍会进行。

### 查询

```postgresql
-- 基础查询
SELECT file_name, file_size, created_at
FROM files
WHERE is_public = true AND file_size > 100000;

-- 模糊查询
SELECT * FROM files WHERE file_name LIKE '%.pdf';

-- 数组查询
SELECT * FROM files WHERE '视频' = ANY(tags);
```

### 修改

```postgresql
-- 模拟下载次数自增
UPDATE files
SET download_count = download_count + 1
WHERE file_name LIKE '%.mp4';

-- 修改多个字段并切换布尔值
UPDATE files
SET is_public = false, tags = arrary_append(tags, '私有')
WHERE file_id = '查出来的某个 UUID';
```

### 删除

```postgresql
-- 删除特定文件
DELETE FROM files WHERE file_id = 'UUID';

-- 删除所有下载次数为 0 的就配置文件
DELETE FROM files
WHERE download_count = 0 AND tags @> ARRAY['测试'::text];
```

### 创建 + 回显

```postgresql
-- 插入并立刻返回新生成的 UUID 和 创建时间
INSERT INTO files (file_name, file_size)
VALUES ('操比王子的实战视频.mp4', 999999)
RETURNING file_id, created_at;
```
